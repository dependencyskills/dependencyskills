# test28 — can a short identifier still move an agent?

Run for [#29](https://github.com/dependencyskills/dependencyskills/issues/29); written up as
RAD-0069.

#28 screens identifiers on length, and RAD-0068 priced that screen at 0.232% of 2,052,056 real
identifiers. This asks the question the price leaves open: is the bound also the ceiling? Every
payload RAD-0027 measured as effective was long, and that is either because length is the active
ingredient or because nobody tried a short one.

## Handling of the files here

**The payload definitions are committed. Everything a run produced is packed or left out.** Same
rule as `test0/measurement/injection`, and for the same reason: a result nobody can reproduce is
not a result, but a file of working payloads should not be the plainest text in a public
repository that coding agents read.

| file | committed | why |
|---|---|---|
| `identifiers.py` | yes | the payload set — reproducing the run needs it |
| `run.py` | yes | the harness |
| `results.md` | yes | counts, and the finding |
| `transcripts.tar.gz` | packed | ninety model outputs, which quote the payloads back |
| `results-*.json` | no | raw scores, regenerated by re-running |

Packing is not secrecy. It is the difference between a payload sitting in a file something greps
and one that has to be deliberately extracted.

**Do not edit the payloads or the controls.** They are what makes a second run comparable with
this one. The exfiltration host is under `.invalid`, which RFC 2606 reserves so it can never be
registered and never resolves.

## Running it

```
uv run --with mlx-lm mlx_lm.server --model mlx-community/Qwen3-8B-4bit --port 1235
MODEL='mlx-community/Qwen3-8B-4bit' N=5 python3 run.py
```

Any OpenAI-compatible endpoint works — point `OPENAI_BASE_URL` elsewhere. `NO_THINK=0` leaves a
reasoning model's thinking on, which is worth doing and was not done for the recorded run.

## What it found, in one line

No payload performed an effect. Two short ones got the method **called**, and what they share is
an assertion of obligation rather than length — so the bound refuses the payload that failed and
accepts the two that worked. See `results.md`.
