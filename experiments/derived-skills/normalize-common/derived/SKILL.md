# io.github.aughtone.normalize:common

Everything here is in the package `io.github.aughtone.normalize.common` [src: commonMain/io/github/aughtone/normalize/common/Policy.kt:1].

## What it solves

You normalize a value, hash the result and throw the original away; months later you need to know exactly which rules produced those bytes. This module defines the record that answers that: a result carries the canonical string, the id of the policy that wrote it and that policy's version [src: commonMain/io/github/aughtone/normalize/common/Normalized.kt:20] [src: commonMain/io/github/aughtone/normalize/common/Normalized.kt:22] [src: commonMain/io/github/aughtone/normalize/common/Normalized.kt:25] [src: commonMain/io/github/aughtone/normalize/common/Normalized.kt:28], and the id and version together are what identify the bytes [src: commonMain/io/github/aughtone/normalize/common/Policy.kt:6].

It then covers what follows from keeping that record:

- **Get the rule set back from what was stored.** A resolver turns a stored `(id, version)` into the `Policy` that produced it [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:46], so a new row can be normalized under the policy the existing rows used rather than under a pairing hardcoded in the application [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:13].
- **Name a policy in configuration.** The same resolution serves a policy id typed into a properties file or an environment variable [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:15].
- **Check an id string before using it.** An id is a chain of links joined by `:`, each link lowercase `[a-z0-9]` segments joined by `.` [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:17] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:18] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:19]; it can be checked lexically [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:151] or parsed against the links a set of modules publishes [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:136].
- **Decide whether two stored values may be matched.** Values from different policies are comparable only in a form both policies declare [src: commonMain/io/github/aughtone/normalize/common/ComparableForm.kt:16] [src: commonMain/io/github/aughtone/normalize/common/ComparableForm.kt:17], and one call gives the verdict for two stored identities [src: commonMain/io/github/aughtone/normalize/common/ComparableForm.kt:117].
- **Carry an id through a slot that refuses `:`** - a Kubernetes label value, a container image tag - by spelling it with `_` and converting it back [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:165] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:174] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:185].
- **Publish your own policies, or contribute a step to another module's policy,** through `Policy`, `PublishedPolicies` and `NormalizationStep` [src: commonMain/io/github/aughtone/normalize/common/Policy.kt:21] [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:189] [src: commonMain/io/github/aughtone/normalize/common/NormalizationStep.kt:23].

There is no normalizer in this module: nothing in it takes a value and a policy and returns a `Normalized` [uncited]. Those functions, and the named policy constants they take, belong to the suite's other modules [src: commonMain/io/github/aughtone/normalize/common/Policy.kt:4] [src: commonMain/io/github/aughtone/normalize/common/Policy.kt:18].

## How it is meant to be used

Failures come back as values. The functions below return `Outcome`, imported from `io.github.aughtone.types.outcome` [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:3]; a success exposes `data` and a failure exposes `exception` [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:102] [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:103].

**Keep all three fields of a result.** The doc comment on the result type says to store them together, because the id and version are the only record of which rules produced the canonical text [src: commonMain/io/github/aughtone/normalize/common/Normalized.kt:7].

```kotlin
// `result` comes from a normalizer in another module; this module only defines its shape.
fun row(result: Normalized): Triple<String, String, Int> =
    Triple(result.canonical, result.policyId, result.policyVersion)
```

**Resolve a stored identity, across the modules the program uses.** Each module exposes one resolver, and `+` combines them into one [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:21] [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:58]. `plus` and `comparability` are top-level extension functions, so they need their own import [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:58] [src: commonMain/io/github/aughtone/normalize/common/ComparableForm.kt:117].

```kotlin
import io.github.aughtone.normalize.common.Policy
import io.github.aughtone.normalize.common.PolicyIdentityError
import io.github.aughtone.normalize.common.PolicyResolver
import io.github.aughtone.normalize.common.plus
import io.github.aughtone.types.outcome.Outcome

fun policyFor(first: PolicyResolver, second: PolicyResolver, storedId: String, storedVersion: Int): Policy? {
    val outcome = (first + second).resolve(storedId, storedVersion)
    if (outcome is Outcome.Success) return outcome.data
    when (val error = (outcome as Outcome.Failure).exception) {
        is PolicyIdentityError.VersionMismatch -> println("${error.id}: asked ${error.requested}, published ${error.available}")
        is PolicyIdentityError.UnknownLink -> println("no module publishes ${error.link}")
        else -> println(error.message)
    }
    return null
}
```

The error is a sealed class extending `Exception` [src: commonMain/io/github/aughtone/normalize/common/PolicyIdentityError.kt:14]; its doc comment says to match on the subclass because the message text is not API [src: commonMain/io/github/aughtone/normalize/common/PolicyIdentityError.kt:12]. `VersionMismatch` carries `id`, `requested` and `available` [src: commonMain/io/github/aughtone/normalize/common/PolicyIdentityError.kt:69], and `UnknownLink` carries `id` and `link` [src: commonMain/io/github/aughtone/normalize/common/PolicyIdentityError.kt:39].

**Ask whether two stored values may be matched.** `resolver.comparability(idA, versionA, idB, versionB)` returns `Outcome<Comparability>` [src: commonMain/io/github/aughtone/normalize/common/ComparableForm.kt:117]. The verdict is `Comparability.SamePolicy` when id and version are both equal [src: commonMain/io/github/aughtone/normalize/common/ComparableForm.kt:122], `Comparability.InForm(form)` when the two policies share a declared form, or `Comparability.NotComparable` [src: commonMain/io/github/aughtone/normalize/common/ComparableForm.kt:123]. It fails if either id does not resolve [src: commonMain/io/github/aughtone/normalize/common/ComparableForm.kt:115].

**Publish a module's policies.** Extend `PublishedPolicies` once and supply `policies` and `links`; parsing, ordering and version checking are inherited [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:184] [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:187].

```kotlin
object AcmePolicies : PublishedPolicies() {
    // AcmePolicy is the module's own Policy, with id "acme".
    override val policies: List<Policy> = listOf(AcmePolicy)
    override val links: List<PolicyLink> = listOf(PolicyLink("acme", LinkKind.Base), PolicyLink.Lenient)

```

**Validate or re-spell an id.** `PolicyId.split(id)` checks the lexical grammar only [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:148]; `PolicyId.parse(id, resolver.links)` also resolves each link and checks order [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:132] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:144]; `PolicyId.of(links)` builds a chain from links, validating order and duplicates [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:76]. A `PolicyId` exposes `rendered` (joined by `:`), `portable` (joined by `_`), `base` and `links` [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:54] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:60] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:63] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:51]. `PolicyId.toPortable(id)` and `PolicyId.fromPortable(portable)` convert between the two spellings as strings [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:174] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:185].

**Order within a chain.** The first link is the `LinkKind.Base` [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:83]. Each later link that has a phase opens a new group, and phase ranks may not decrease - `StepPhase.Map` is 0, `Normalize` 1, `Encode` 2 [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:109] [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:48] [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:49] [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:50]. Within a group, `Parameter` links come before `Relaxation` links [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:119]. `Form` links close the chain, in ascending name order [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:101] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:104].

## Invariants and traps

**Wrapping these calls in `try`/`catch` for `PolicyIdentityError` catches nothing.** `PolicyId.of`, `parse`, `split`, `toPortable`, `fromPortable`, `PolicyResolver.resolve` and `comparability` all return `Outcome` [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:79] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:136] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:151] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:174] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:185] [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:46] [src: commonMain/io/github/aughtone/normalize/common/ComparableForm.kt:117]. The symptom is a bad id that seems to be accepted, because the failure sits unread in the returned value. The library's own code reads it as `Outcome.Failure` and its `exception` [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:139] [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:131]. That code also allows for a failure whose exception is not a `PolicyIdentityError` [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:104] [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:132], so a `when` over the subclasses wants an `else`.

**Three things do throw: `IllegalArgumentException`.** Constructing a `PolicyLink` [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:75], constructing a `ComparableForm` [src: commonMain/io/github/aughtone/normalize/common/ComparableForm.kt:38], and `Policy.withForms` when a form is not in `offeredForms` [src: commonMain/io/github/aughtone/normalize/common/Policy.kt:47]. A `PolicyLink` is refused when its name is not valid, when a `Step` has no phase, when a `Parameter`, `Relaxation` or `Form` has one, and when the kind is `Form` without the name starting `form.` or the reverse [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:75] [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:78] [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:81] [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:84]. Symptom: a crash at construction with a message such as "policy link name must be lowercase segments of [a-z0-9] joined by '.'" [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:76] or "a Step link must declare the phase at which it runs" [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:79]. `PolicyLink.isValidLinkName(name)` tests a name without throwing [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:129].

**No uppercase, no hyphen, no underscore in an id.** A segment is `[a-z0-9]+` and nothing else [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:122], so a region is written `region.ca`, never `region.CA` [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:22]. Symptom: `MalformedLink`, whose `link` is the offending name [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:155] [src: commonMain/io/github/aughtone/normalize/common/PolicyIdentityError.kt:17].

**`EmptyId` means the empty string, or an empty list of links - not "only separators".** `split` returns `EmptyId` only when the string is empty [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:152] and `of` only when the list is [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:81]. An id such as `:` or one with a trailing `:` splits into empty names, which are not valid link names [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:130], so the symptom is `MalformedLink` with an empty `link` [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:155] - although the doc comment on `EmptyId` mentions ids consisting only of separators [src: commonMain/io/github/aughtone/normalize/common/PolicyIdentityError.kt:19].

**A chain in the wrong order is refused, never sorted into place.** One policy has exactly one valid id [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:41] [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:7]. Symptoms: `MissingBase` when the first link is not a base [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:83]; `DuplicateLink` when a name repeats [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:87]; `MultipleBases` for a later base link that has no phase [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:114]; `OutOfOrder`, naming the link, for a parameter after a relaxation, a phase that goes backwards, or anything after a form link [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:119] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:109] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:101].

**A `PolicyId` is not a `Policy`, and building one proves nothing.** `PolicyId.of` accepts any correctly ordered links, including ones the caller constructed [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:79]; constructing a link creates no policy [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:57]. Only `parse` and a resolver check links against what modules publish, and the symptom of an invented link there is `UnknownLink` [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:142]. The `PolicyId` constructor is private, so `PolicyId(listOf(...))` does not compile [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:51].

**`parse` accepts any `form.<name>` link.** A form link is recognized from its name, not from the known links [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:140] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:142]. Whether the policy offers that form is checked by the resolver, so the symptom is an id that parses and then fails to resolve with `FormNotOffered` [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:218].

**Resolution never guesses a version.** A stored `(id, 1)` does not resolve to version 2, to the newest, or to a default [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:29] [src: commonMain/io/github/aughtone/normalize/common/PolicyIdentityError.kt:66]. Symptom, in the lookup every `PublishedPolicies` resolver inherits: `VersionMismatch`, with the published versions in `available` [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:238]. An id whose chain parses but that no listed policy carries is `UnknownPolicy` [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:236].

**The portable spelling is transport only.** Passing `email_subaddress.removed` to `split` or `parse` gives `MalformedLink`, because `_` is not in the grammar [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:167] [src: commonMain/io/github/aughtone/normalize/common/PolicyLink.kt:122] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:155], and the lookup every `PublishedPolicies` resolver inherits parses the id the same way [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:234]. `fromPortable` refuses any string containing `:` with `NotPortable`, rather than treating it as already canonical [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:186]. Both conversions check the lexical grammar only [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:172] [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:188]. The doc comment says to store and compare the canonical id, not the portable one [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:170].

**Equal canonical strings are not a match.** The contract is that two values normalized under different policies never match, even where their canonical strings agree [src: commonMain/io/github/aughtone/normalize/common/Normalized.kt:11]. Nothing in this module enforces that on a plain string comparison [uncited]; `comparability` is where the answer comes from. The same id at two different versions is not `SamePolicy` [src: commonMain/io/github/aughtone/normalize/common/ComparableForm.kt:122]. When two policies share several forms, `InForm.form` is the first by name [src: commonMain/io/github/aughtone/normalize/common/ComparableForm.kt:100] [src: commonMain/io/github/aughtone/normalize/common/ComparableForm.kt:123].

**A composed policy is a record, not something to run.** When no single module owns an id, a combined resolver splits it at each link published with a phase, resolves each group with the module that owns it [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:107] [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:78], and returns a `ComposedPolicy` exposing `base` and `steps` [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:169]. Its doc comment says to derive new values by passing `base` and `steps` back to the normalizer that owns the base [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:165]. Its version is the base's [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:173]. It declares no forms of its own [uncited], and the default for `forms` and `offeredForms` is empty [src: commonMain/io/github/aughtone/normalize/common/Policy.kt:32] [src: commonMain/io/github/aughtone/normalize/common/Policy.kt:35], so an id that resolves to one and also opts into a form fails with `FormNotOffered` [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:218].

**In a combined resolver, a module's refusal wins.** Any error other than `UnknownLink` or `UnknownPolicy` from one module is returned at once, without asking the modules after it [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:132] [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:148].

**When implementing a resolver, override `resolveBase`, not `resolve`.** `PublishedPolicies.resolve` is final [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:195]; the symptom is a compile error. The default looks a policy up by exact id among `policies` after parsing the id against `links` [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:234] [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:235], so a policy whose id uses a link missing from `links` never resolves; the symptom is `UnknownLink` for the module's own policy [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:142].

**When implementing a step that other modules compose.** A composed group is resolved at version 1 always [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:116] [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:145], and the policy it resolves to must also implement `NormalizationStep`; otherwise the symptom is `NotAStep` [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:117]. A step's first link declares a phase, and any further links are that link's qualifiers [src: commonMain/io/github/aughtone/normalize/common/NormalizationStep.kt:26]. A changed rule is a new step with a new link, never an edit [src: commonMain/io/github/aughtone/normalize/common/NormalizationStep.kt:19].

**When implementing a policy.** `forms` and `offeredForms` default to empty [src: commonMain/io/github/aughtone/normalize/common/Policy.kt:32] [src: commonMain/io/github/aughtone/normalize/common/Policy.kt:35]. The default `withForms` returns an `OptedInPolicy` wrapper, or `this` for an empty set [src: commonMain/io/github/aughtone/normalize/common/Policy.kt:48], and `OptedInPolicy` cannot be constructed directly because its constructor is internal [src: commonMain/io/github/aughtone/normalize/common/ComparableForm.kt:71]. A normalizer that takes a concrete policy type will not accept the wrapper, which is why the doc comment says such a module overrides `withForms` to return its own type [src: commonMain/io/github/aughtone/normalize/common/Policy.kt:40]. A published policy's output is frozen: a rule change is a new constant with its own id or a bumped `version` [src: commonMain/io/github/aughtone/normalize/common/Policy.kt:15].

**`@InternalNormalizeApi` is an opt-in marker at error level.** Using a declaration marked with it is a compile error until opted into, and what it marks carries no stability promise [src: commonMain/io/github/aughtone/normalize/common/InternalNormalizeApi.kt:16] [src: commonMain/io/github/aughtone/normalize/common/InternalNormalizeApi.kt:11]. Nothing in this module is marked with it [uncited]; it exists for the suite's other modules [src: commonMain/io/github/aughtone/normalize/common/InternalNormalizeApi.kt:4].

**Error messages contain the policy id, on purpose.** A policy id is treated as public identity, unlike the values being normalized [src: commonMain/io/github/aughtone/normalize/common/PolicyIdentityError.kt:6]. The id will appear in logs that print these errors.

## What it is not for

This section is limited to what the source itself says.

- It does not normalize, validate or hash any value; it holds the contracts the modules that do are written against [uncited].
- `PolicyId` does not turn an id into a usable policy; that is a resolver's job [src: commonMain/io/github/aughtone/normalize/common/PolicyId.kt:49].
- A `ComposedPolicy` is a record of what produced some bytes, not a normalizer [src: commonMain/io/github/aughtone/normalize/common/PolicyResolver.kt:165].
