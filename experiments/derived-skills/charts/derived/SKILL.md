## What it solves

Putting a chart on screen in a Compose UI without writing the Canvas code, the axis maths or the legend yourself. Each need below is one composable.

**Provide the palette once, above the charts, then call a chart with a sized modifier.**

```kotlin

    categories = listOf(
        BarChartCategory(
            name = "Q1",                                   // label under the cluster

        ),
    ),
)

CompositionLocalProvider(
    LocalChartColors provides ChartDefaults.chartColors(surface = MaterialTheme.colorScheme.surface),

}
```

**A line chart is points at epoch-millisecond timestamps, and you supply the time formatting.**

```kotlin

    series = listOf(
        LineChartSeries(
            dataName = "Indoor",
            lineColor = Color(0xFF1565C0),
            listOfPoints = listOf(
                LineChartPoint(x = 1_700_000_000_000, y = 21.5f),   // x: Long epoch ms, y: Float

    modifier = Modifier.fillMaxWidth().height(280.dp),
```

## Invariants and traps

**No palette provided.** `LocalChartColors` defaults every colour to `Color.Unspecified`; nothing falls back to the Material theme unless `ChartDefaults.chartColors()` is provided above the chart. [src: commonMain/io/github/aughtone/charts/theme/Theme.kt:10] [src: commonMain/io/github/aughtone/charts/theme/Theme.kt:20] Symptom: the themed parts are missing or the wrong colour — grid lines on bar and line charts, the arc and scale of a dial — while bars and lines, coloured from the data, still appear. [src: commonMain/io/github/aughtone/charts/bar/BarChartColors.kt:22] [src: commonMain/io/github/aughtone/charts/dial/DialColors.kt:24]

**The touch balloon has no background by default.** `ChartDefaults.chartColors()` leaves `surface` as `Color.Unspecified`, and `surface` is the only thing drawn behind the balloon on bar and line charts. [src: commonMain/io/github/aughtone/charts/theme/ChartDefaults.kt:32] [src: commonMain/io/github/aughtone/charts/OverlayInformation.kt:49] Symptom: the balloon's text sits straight on top of the plot. Passing `surface = …` to `chartColors` gives it one.

**Three "how full" scales.** `GasBottle` takes a `Float` from 0 to 100 and clamps to that range; `ArcProgressBar` takes a `Float` from 0 to 1 and clamps to that; `Dial` and `PercentageDial` take `Int`. [src: commonMain/io/github/aughtone/charts/gasbottle/GasBottle.kt:89] [src: commonMain/io/github/aughtone/charts/simple/ArcProgressBar.kt:44] [src: commonMain/io/github/aughtone/charts/dial/Dial.kt:63] Symptom of a 0-to-1 fraction handed to `GasBottle`: a bottle that always looks empty. Symptom of a percentage handed to `ArcProgressBar`: an arc that is full for any value of 1 or more. `GasBottle` also draws anything from 1 to 5 as 5. [src: commonMain/io/github/aughtone/charts/gasbottle/GasBottle.kt:90]

**`ChartAnimation.Sequenced` crashes the single-value charts and the pie.** `PieChart`, `Dial` and `GasBottle` throw `UnsupportedOperationException` during composition when given it. [src: commonMain/io/github/aughtone/charts/pie/PieChart.kt:73] [src: commonMain/io/github/aughtone/charts/dial/Dial.kt:85] [src: commonMain/io/github/aughtone/charts/gasbottle/GasBottle.kt:60] So do `PercentageDial` and `PieChartWithLegend`, which pass their animation straight through. [src: commonMain/io/github/aughtone/charts/dial/PercentageDial.kt:30] [src: commonMain/io/github/aughtone/charts/pie/PieChartWithLegend.kt:39] Symptom: a crash whose message says `Sequenced` is not supported.

**`PieChart` with `ChartAnimation.Disabled` draws a one-degree pie.** In that branch the full sweep is `1f`, where the animated branch runs up to 360, and every segment's angle is scaled to that total. [src: commonMain/io/github/aughtone/charts/pie/PieChart.kt:64] [src: commonMain/io/github/aughtone/charts/pie/PieChart.kt:68] [src: commonMain/io/github/aughtone/charts/pie/PieChart.kt:121] Symptom: an almost empty square with a hairline sliver where the pie should be. `ChartAnimation.Simple` is the mode that draws a whole pie. ## What it is not for

Where the maintainers draw the line is not written in the source; this is what the source does not contain. [uncited]

- Chart kinds other than those listed: no scatter, stacked or horizontal bar, radar or candlestick chart. [uncited]
