# Architecture Decision Records

Each record is one hard-to-reverse choice: the forces that pressed on it,
the decision, and — more importantly — what was tried and abandoned first.
Read these before proposing a structure or layout change; several
alternatives were considered and rejected here with reasons, and each looks
correct until it meets a concrete case. Records are append-only: a
superseded decision is marked, never rewritten.

The records here are the decisions that have **settled** — the shape of the
repository, how the docs tree is organised, which ecosystem conventions the
project adopts. Decisions still being worked out — how a library skill
travels, how the index works — live in Research until they lock, then
graduate here. An ecosystem-specific technical decision gets its own record
rather than being folded into another.
