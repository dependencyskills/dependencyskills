# Documents

Informational pages that explain the project — what it is, why it exists, and how its pieces relate. They are maintained in place rather than dated and closed, so a document here describes how things stand now rather than what was true when someone wrote it.

This is also the honest home for a page that fits no other section. That makes it the last stop rather than the easy one: a decision belongs in Architecture Decision Records and an investigation belongs in Research, and one filed here instead is lost to everyone looking for it where it should have been.
